## 🌟 ¿Qué es este repositorio?

Este repositorio reúne los **ejercicios y programas desarrollados en la Actividad 5**. Incluye desde algoritmos básicos en Python (números primos, pares, divisibilidad) hasta una aplicación web interactiva llamada **InfoVIH**, que funciona como asistente educativo sobre el VIH/SIDA usando inteligencia artificial.

Es un proyecto que combina **lógica de programación** con **conciencia social**, mostrando cómo el código puede servir tanto para aprender como para educar.

## 🔢 Programa 1 — `par_primo_divisible.py`

Este script recibe un número y realiza **tres análisis**:

| Análisis | ¿Qué hace? |
|:---:|:---|
| **Par / Impar** | Verifica si el número es divisible entre 2. |
| **Primo / Compuesto** | Comprueba si solo tiene dos divisores (1 y él mismo). |
| **Divisibilidad** | Indica si el número es divisible por otros valores. |

### 💡 Ejemplo de uso

```bash
python par_primo_divisible.py
